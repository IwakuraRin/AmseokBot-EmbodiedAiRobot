# NasForWindows Web

Angular 22 + Angular Material frontend scaffold for the Windows storage-management service.

## Commands

```bash
npm install
npm start
npm run check
```

The development server listens on `http://localhost:4200` by default. The production build is intended to be served by the ASP.NET Core host.

## Typography

The application and all Angular Material components use Source Sans 3 for Latin text and Source Han Sans CN for Simplified Chinese. Typography is configured once in `src/material-theme.scss`; component-specific font overrides are not allowed.

See the repository root `ARCHITECTURE.md` before adding a feature or plugin renderer.
